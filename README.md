# Scientific Graphing Calculator (Enhanced)

## Overview
This project is an enhanced scientific graphing calculator built in Java using Swing. It allows users to evaluate mathematical expressions, solve equations, graph functions, and manage calculation history with save/load functionality.  

---

## Features

1. **Expression Evaluation**
   - Supports `+`, `-`, `*`, `/`, `^`.
   - Variables (`x`) and constants (`pi`, `e`).
   - Functions: `sin`, `cos`, `tan`, `log`, `ln`, `sqrt`.

2. **Equation Solving**
   - Bisection method for numerical roots.
   - Solve `f(x) = g(x)` in a specified interval.

3. **Graphing**
   - Real-time plotting of functions.
   - Zooming, panning, and grid toggle.
   - Displays x-intercepts, y-intercept, and approximate range.

4. **History Management**
   - Scrollable calculation history.
   - Save/load history to/from `history.txt`.

5. **Two-Screen Interface**
   - Left panel: input, keypad, and history.
   - Right panel: graph and controls.
   - Resizable split for comfortable viewing.

6. **Keyboard Shortcuts**
   - Enter key evaluates input (same as `=`).

---

## How to Run

1. Put all files in a `src` directory.
2. Run Calculator.GUI
